# El Menshawi Rent Car

Landing page for El Menshawi Rent Car ([elmenshawirentcar.com](https://elmenshawirentcar.com)).

## Content

All page text, images, and links are driven from a single file:

```
src/content/content.js
```

Edit that file to change copy, links, or swap images (images live in `public/images/`) — no component code needs to change.

## Running the project

```bash
npm install
npm run dev
```

Other scripts:

```bash
npm run build    # production build
npm run preview  # preview the production build locally
npm run lint     # lint the codebase
```
